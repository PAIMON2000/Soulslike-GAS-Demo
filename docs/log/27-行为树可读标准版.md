# 行为树可读标准版

日期：2026-11-08。

用户指出上一轮“执行已选行动｜按Action匹配”下面仍然堆放大量Action，难以理解；随后明确认可按行为意图分层，并要求实际制作标准版本。

上一轮把可读性主要理解为中文命名，遗漏了层级组织和选择依据。本轮新建战斗总览与四类行动子树：近身攻击、远距攻击、位置与朝向调整、特殊事件与变体。编号退到来源说明中。总览21个运行节点，原版89个；类别不引入二次抽取，原11种行动的顺序、装饰器和任务配置逐项重载对比。

当前控制器绑定`StandardReadable/BT_DS3_CombatOverview`与`BB_DS3_Standard`。原树和黑板保留；控制器修改前备份在`LocalBackups/DS3Standard-2026-11-08`。回退需同时恢复树与黑板绑定。

运行测试暴露原黑板TargetActor为通用Object，UE5.8保存校验会清空MoveTo目标。标准版以独立黑板将其明确为Actor，并正常保存两次验证，不再依赖临时清除类型过滤器的保存方式。修复后17项运行检查通过。

中间曾尝试重建旧图并恢复对象名，发生重名崩溃，随后自动审核拒绝继续。该方案已停用；正式版通过公开属性新建独立资产，仅在新资产创建其编辑图，没有删除或重命名原资产对象。失败的试建资产不接入控制器，也不纳入正式内容快照。

这是用户明确表达的阅读需求：人应先看行为意图，再看选择条件、执行过程与结束条件。适用于本项目AI研究与维护；不将此解释为用户已认可某种战斗风格，也不将运行测试等同于可读性体验验收。后续需用户实际阅读后反馈。
