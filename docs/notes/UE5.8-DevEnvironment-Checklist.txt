 本机虚幻引擎开发环境清单（重装新电脑用）
 项目：ProjectUnreal (Soulslike-GAS-Demo)  引擎：Unreal Engine 5.8
 整理日期：2026-10-25
================================================================================

--------------------------------------------------------------------------------
一、操作系统
--------------------------------------------------------------------------------
- Windows 11 25H2（内部版本 26200，64 位）
  说明：UE5.8 最低要求 Win10 64-bit (20H2 及以上)，推荐 Win11。
  新机器装 Win11 64 位即可。

--------------------------------------------------------------------------------
二、Visual Studio 2022（核心依赖）
--------------------------------------------------------------------------------
版本：Visual Studio Community 2022，17.14.23（安装器通道：release 17.14）
许可证：Community（个人/开源项目免费，需要登录微软账号）

工作负载（Workloads）：
  [x] 使用 C++ 的游戏开发 (NativeGame)
  [x] 使用 C++ 的桌面开发 (NativeDesktop)
  [x] .NET 桌面开发 (ManagedDesktop)
  [x] 核心编辑器 (CoreEditor)
  （已安装但非 UE 必需：ManagedGame、NativeMobile、Universal、
    VisualStudioExtension）

单个组件（必装项）：
  [x] MSVC v143 - VS 2022 C++ x64/x86 生成工具 (v14.44, 最新)
  [x] MSVC v143 - VS 2022 C++ x64/x86 生成工具 (v14.38-17.8)
      -- 说明：本机装了两个 v143 工具集版本，UE 默认用最新即可，
         14.38 为旧版本兼容，可不装
  [x] C++ MFC (适用于 v143 生成工具) —— 即 .vsconfig 中的 ATL 组件
  [x] Windows 11 SDK (10.0.22621.0)
  [x] Windows 11 SDK (10.0.26100.0)
      -- 说明：装其中一个即可，UE5.8 默认使用较新的 10.0.26100
  [x] .NET Framework 4.6.2 目标包
  [x] 适用于 Windows 的 C++ Clang 工具 (LLVM/Clang)
  [x] Unreal Engine 测试适配器 / Unreal Engine 集成（IDE 支持）
      组件ID：Component.Unreal.Debugger、Component.Unreal.Ide

>>> 快捷方式：项目根目录下的 .vsconfig 文件已包含最小组件集，
>>> 新机器装好 VS 安装器后双击 .vsconfig，或在 VS Installer 中
>>> "导入配置" 即可一键勾选上述组件。

下载地址：https://visualstudio.microsoft.com/zh-hans/vs/community/

--------------------------------------------------------------------------------
三、虚幻引擎本体
--------------------------------------------------------------------------------
- 引擎版本：Unreal Engine 5.8.4（Release-5.8 分支，官方二进制安装）
- 本机位置：E:\UE_5.8（约需 100+ GB 磁盘空间，建议 SSD）
- 安装方式：Epic Games Launcher -> 虚幻引擎库 -> 安装 5.8.x
  下载地址：https://www.unrealengine.com/zh-CN/download
  （安装时勾选 "启动程序 prerequisites / .NET prerequisites"）

- 本机还装有 UE 5.7 (E:\UE_5.7) 和源码目录 (E:\UE5)，新项目可不必安装。

- 引擎关联：项目 ProjectUnreal.uproject 的 EngineAssociation 为 "5.8"，
  新机器上引擎装好并登录 Epic 账号后可直接双击 .uproject 打开；
  若无法识别，右键 .uproject -> "Switch Unreal Engine version" 选 5.8。

--------------------------------------------------------------------------------
四、项目使用的引擎插件（均为引擎自带，随引擎安装，无需额外下载）
--------------------------------------------------------------------------------
  - ModelingToolsEditorMode（建模工具）
  - GameplayAbilities（GAS 技能系统，本项目核心）
  - GameplayStateTree
  - PythonScriptPlugin（编辑器 Python 脚本，Tools/ 下大量构建脚本依赖）
  - ModelContextProtocol
  - EditorToolset
  - GASToolsets

--------------------------------------------------------------------------------
五、其他开发工具（本机已装，按需要重装）
--------------------------------------------------------------------------------
版本控制：
  - Git for Windows 2.46.0
  - Git LFS 3.5.1        （项目 Content/ 资产走 LFS，必装）
    下载：https://git-scm.com/download/win

运行时/SDK：
  - .NET SDK：5.0.408 / 8.0.401 / 9.0.308（装 8.0 即满足 UE 编辑器需要）
    下载：https://dotnet.microsoft.com/download
  - Windows 11 SDK（见 VS 组件部分）
  - Visual C++ 运行库（随 VS 安装自动带上，也可单独装
    "Visual C++ Redistributable for Visual Studio 2015-2022 x64"）
  - DirectX 12（Win11 自带，无需单独安装）
  - .NET Framework 4.8（Win11 自带）

脚本/自动化（项目 Tools/ 目录的 Python 构建脚本用）：
  - Python 3.12（本机位于 %LOCALAPPDATA%\Programs\Python\Python312）
    说明：也可用 UE 自带的引擎内 Python（PythonScriptPlugin），
    或从 https://www.python.org 安装，勾选 "Add to PATH"
  - Node.js v24.13.0（可选，本机用于自动化工具）

显卡驱动：
  - NVIDIA 显卡 + 最新 Game Ready / Studio 驱动
    下载：https://www.nvidia.cn/drivers

--------------------------------------------------------------------------------
六、新机器重装步骤（建议顺序）
--------------------------------------------------------------------------------
  1. 装 Windows 11 64 位，更新到最新补丁
  2. 装最新 NVIDIA 显卡驱动
  3. 安装 VS 2022 Community，导入项目 .vsconfig（或按第二部分勾选）
  4. 安装 Epic Games Launcher，登录后安装 UE 5.8（最新 5.8.x）
  5. 安装 Git + Git LFS；克隆仓库后执行 git lfs pull
  6. 安装 .NET 8 SDK、Python 3.12（可选）
  7. 双击 ProjectUnreal.uproject 首次编译，完成

--------------------------------------------------------------------------------
七、磁盘空间预估
--------------------------------------------------------------------------------
  - UE 5.8 引擎：约 130 GB
  - VS 2022 + SDK/工具集：约 30-40 GB
  - 项目本体（含 .git / Content LFS 资产）：以仓库实际大小为准
  - 建议单盘预留 300 GB 以上（SSD/NVMe）
