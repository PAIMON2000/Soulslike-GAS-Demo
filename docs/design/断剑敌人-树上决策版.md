# 断剑敌人：树上决策版

游戏入口：`/Game/Gameplay/AI/DS3BrokenSword/Tactical/BT_BrokenSword_Combat`。

这次重写的是决策所在的位置。原本在 `BTT_DSDecide` 和 `BTT_DSAfterAttack` 内的局势判断，已迁到行为树条件。第一版沿用已有攻击动作和候选权重，不把可运行原型称作完成了商业品质调校。

## 从哪里看

1. 打开 `BT_BrokenSword_Combat` 看一轮行动的顺序。
2. 双击“① 判断局势”进入 `BT_DecisionRules`，看为什么选择这类行动。
3. 继续打开“队伍职责”“侧后响应”或“正面交战”，看具体条件和候选权重。
4. 回到总览，“② 执行已选招式”内仍是四类执行子树。
5. 双击“③ 攻击后调整”，看是否追加走位，再进入 `BT_RecoveryDistance` 看当前距离对应的选择。

决策子树都在 `Tactical` 文件夹。四类执行子树与共享黑板仍在 `StandardReadable`，它们是正在使用的组件。

## 一轮如何选择

先测量目标距离、方向、自身生命比例和3003冷却，然后从左到右判断：

| 优先级 | 树上的条件 | 结果 |
|---|---|---|
| 1 | 事件请求为100 | 只候选特殊动作20005 |
| 2 | 110054变体 | 只候选专用接近 |
| 3 | 旁观或围攻职责 | 按队伍职责配置候选 |
| 4 | 近距离侧面或符合背向条件 | 侧向攻击与转身，或只转身 |
| 5 | 144041，或144040且生命≤80% | 按13单位距离门槛选择特殊动作 |
| 6 | 其他正面交战 | 远、中、近三个区间配置候选 |

命中一组后不再走后续组。然后，树上的独立冷却条件决定是否移除3003，最后由通用抽签任务从剩余权重中选择一次行动。

权重可以在“配置候选”节点的详情中直接修改。权重不是固定百分比；过滤后重新归一化。近身招式仍可先接近再出手。

## 攻击后怎么走位

普通攻击有50%机会进入调整，特殊动作必定进入，移动行动不追加。进入之后重新测量距离：

| 当前情况 | 调整选择 |
|---|---|
| 旁观／围攻且距离≤6 | 后退到8 |
| 旁观／围攻且距离>6 | 侧移 |
| 普通角色，距离≥6 | 25%侧移，75%靠近到5.5 |
| 距离4～6 | 30%侧移，70%结束 |
| 距离2～4 | 15%侧移，10%后退，75%结束 |
| 距离0.5～2 | 5%侧移，15%后退，80%结束 |
| 距离<0.5 | 15%后退，85%结束 |

以上比例是**已经进入调整之后**的条件概率。普通攻击还要先经过50%门槛。

## 蓝图还负责什么

- `BTT_ReadSituation`：测量数据，不选策略。
- `BTT_SetCandidates`：写入当前树分支的公开权重，不判断局势。
- `BTT_ExcludeCoolingAttack`：执行树要求的冷却过滤。
- `BTT_DrawCandidate`：通用加权抽签，不包含怪物的距离、角色或变体规则。
- `BTT_PrepareRecovery` / `BTT_SetRecovery`：准备随机数、记录树决定的走位方式。
- 原有攻击、移动与连击任务：执行具体动作。

这不是“完全不用蓝图”。选择依据放在树上，测量、数学运算和动作执行留在任务中。通用抽签和原有移动执行图仍有进一步封装空间；这轮没有宣称把所有BTT内部都重构完。

## 中断与本版边界

一轮开始时选择一次，攻击期间不因距离变化重新抽签；攻击结束后重新读取距离。目标失效会中止导航，停止行为树会取消攻击和移动。当前没有新增受击优先分支、攻击取消窗口或团队令牌系统。

动画、伤害、位移与特殊效果沿用项目替代实现。距离仍用现有脚本单位，默认1单位按100厘米换算。是否更好玩需要实际试玩，本次首先验证可读性与原有规则迁移。

验证工具：`Tools/verify_ds3_tactical.py` 检查实际资产条件；`Tools/verify_ds3_tactical_actions.py` 比较11种行动基准；运行与抽样验证分别在 `verify_ds3_tactical_runtime.py`、`verify_ds3_tactical_sampling.py`、`verify_ds3_recovery_sampling.py`。
