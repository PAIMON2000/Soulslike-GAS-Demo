# 断剑敌人行为树：可读标准版

当前总览：`/Game/Gameplay/AI/DS3BrokenSword/StandardReadable/BT_DS3_CombatOverview.BT_DS3_CombatOverview`。旧树`BT_DS3BrokenSword`保留。

## 先看总览

准备本轮战斗 → 根据局势选择一次行动 → 四类行动入口 → 恢复步行与朝向 → 决定攻击后调整 → 调整距离或结束本轮。双击类别节点打开子树。

## 四类行动

### 近身攻击

资产：`/Game/Gameplay/AI/DS3BrokenSword/StandardReadable/BT_DS3_Melee.BT_DS3_Melee`。

- **连击A**：普通正面：远/中/近权重15/20/25。接近后3000→3001；75%追加3002。左侧近距特例权重30。 来源Act01。
- **连击B**：普通正面：远/中/近权重10/20/15。接近后3001→3002；75%追加3000。右侧近距特例权重30。 来源Act02。
- **固定两段攻击**：普通正面：远/中/近权重0/15/15。接近后3002→3001，固定两段。 来源Act04。
- **独立冷却攻击**：普通正面：远/中/近权重10/35/45。接近后3003。最近发动3003后20秒内权重归零，其他招式不受此冷却限制。 来源Act05。

### 远距攻击

资产：`/Game/Gameplay/AI/DS3BrokenSword/StandardReadable/BT_DS3_Ranged.BT_DS3_Ranged`。

- **远距前冲攻击**：普通正面远距权重45，中近距为0；围攻角色远距权重20。先接近至本招距离，再执行3007；前冲动画与位移是项目替代实现。 来源Act06。

### 调整位置与朝向

资产：`/Game/Gameplay/AI/DS3BrokenSword/StandardReadable/BT_DS3_Spacing.BT_DS3_Spacing`。

- **后退拉开距离**：旁观角色权重60，围攻角色权重50。必要时接近，再后退；最长4秒，目标间距10脚本单位。 来源Act11。
- **围绕目标侧移**：普通正面远/中/近权重20/10/0；旁观40、围攻30。侧移最长2秒，保留已有范围退出条件。 来源Act12。
- **转身面向目标**：侧面近距权重55，背向目标的匹配条件下权重100；选招兜底亦可进入。转身最多3秒，角度门槛随机15～20度。 来源Act13。

### 特殊事件与变体

资产：`/Game/Gameplay/AI/DS3BrokenSword/StandardReadable/BT_DS3_Special.BT_DS3_Special`。

- **特殊动作20005**：事件请求100直接进入；144041或低血量144040在距离≥13时选此行动；未触发低血量的144040也可获得附加权重。执行20005，特殊效果尚为近战替代。 来源Act20。
- **特殊动作20006**：144041或低血量144040在距离<13时选此行动；未触发低血量的144040也可获得附加权重。执行20006，特殊效果尚为近战替代。 来源Act21。
- **110054变体专用接近**：ThinkParamID=110054且未被更高优先事件覆盖时，直接执行专用接近。 来源Act54。

## 如何理解选择规则

选招只在本轮开始执行一次：事件请求 → 110054变体 → 队伍角色 → 侧后方向 → 144040/144041触发 → 普通距离权重与变体附加权重 → 3003冷却过滤 → 按剩余权重抽取。普通距离区间：远≥5.5，中1.5～5.5，近<1.5，均为脚本单位。权重不是恒定百分比。

四类是阅读分组。不会先抽类别再抽动作，也不代表距离外不能选择近身招式；近身攻击仍可先寻路接近。权重经过特例和冷却过滤后才归一化。

## 边界与验证

新资产的每种行动保持原任务配置、子节点顺序、装饰器及其逻辑。选招任务、攻击后调整任务、伤害与动画资源均沿用当前原型。动画、位移与特殊效果的替代边界见[原复刻说明](断剑敌人行为树复刻.md)。

整理器可导入`ashen-tree/data/断剑敌人-可读标准版.json`。导入前先导出个人编辑记录；通用示例推演不支持原生子树、随机权重和中断，档案有意用UNKNOWN守卫阻止误演。

标准版使用独立`BB_DS3_Standard`，将TargetActor明确为Actor，修复UE正常保存时清空寻路目标的类型校验问题。原黑板保留。控制器同时绑定标准总览与标准黑板；回退需同时恢复两者。
