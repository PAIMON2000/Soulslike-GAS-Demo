# 断剑怪 behaviac 整理稿

打开 BrokenSword.workspace.xml。00是完整循环，01保留全部19条分支，02只展示基础配置下的方向与间距规则。10至22为常规行动，30至32为共用恢复，40至42为待核实的特殊分支。双击引用子树可继续阅读。

这是一套可编辑的设计稿。游戏方法是占位声明，未接入或改动UE。间距仍为原脚本单位。接近时限、外部请求来源、角色枚举映射、恢复随机值生成与中断取消需要核对。

使用标准选择、顺序、条件、概率选择、权重、子树引用、并行、等待和结果修饰节点。冷却先通过条件分叉，再在相应候选中抽签。接近超时通过并行等待后失败表示，避免把时长节点误当成超时失败。

重新运行上级目录 build-behaviac-workspace.cjs 会覆盖生成内容；在编辑器手调前另存工作区。
