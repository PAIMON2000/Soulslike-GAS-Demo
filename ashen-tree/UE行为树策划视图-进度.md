# UE 行为树策划视图

断剑怪的第一版策划树已整理成可在 behaviac Designer 中打开的工作区。`00` 是完整战斗循环，`02` 是普通断剑怪的方向与间距判断。移动、攻击等方法目前是供编辑器使用的接口声明。插件仍处于方案阶段。[behaviac 工作区](behaviac-workspace/BrokenSword.workspace.xml)

## 第一版范围

优先做 UE 编辑器插件，直接读取原生 `UBehaviorTree` 资产。用横向布局展示树结构，同级分支从上到下呈现 UE 实际执行顺序。把条件放在对应行动旁边，显示可读的参数与中断方式，支持折叠分支、打开子树和定位原生节点。第一版先验证读取与呈现，之后再做少量参数编辑并支持撤销。[UE 行为树编辑器 API](https://dev.epicgames.com/documentation/unreal-engine/API/Editor/BehaviorTreeEditor)

视图只展示 UE 资产能提供的结构与参数。蓝图任务内部的判断要在原树中明确组织，才能在视图中顺着分支读懂。behaviac 工作区可作为断剑怪结构评审和后续重搭的参考。

## 独立开发与验收

公司电脑使用同版本 UE 的空白 C++ 工程或插件测试宿主，以自建行为树覆盖选择器、顺序器、黑板条件和子树。公司电脑无需检出游戏工程。若本机没有对应 UE 版本和 C++ 工具链，可以先完成界面原型和插件源码，实际编译放到具备工具链的环境。

空工程阶段验证视图顺序、条件与原生资产一致，并验证子树和节点定位。之后在已有完整工程的电脑上用断剑怪实树验收，再决定是否加入参数编辑。跨引擎导入和 behaviac 运行时接入属于独立方案。
