# 断剑怪物行为树：本地整理与说明

## 策划阅读树副本（2026-11-10）

用浏览器打开 [断剑怪·策划阅读树](断剑怪-策划阅读树.html)。提供一轮战斗、普通怪物选招、完整条件树与行动子树入口，支持横向展开、折叠、平移与缩放。共享子树只维护一份，数据见 [策划阅读树 JSON](data/断剑怪-策划阅读树.json)。

此版本是本地设计副本，尚未接入UE。保留19条规则的候选和权重，覆盖11种行动；距离换算、外部请求来源及部分执行细节仍需核对。结果转成功、超时与中断语义需要在UE验证。已完成数据与导航逻辑检查，尚未完成浏览器画面验收。

重新生成时，在本目录依次运行 `node build-planner-tree.cjs` 和 `node render-planner-tree.cjs`。


直接用浏览器打开 [断剑怪物行为说明](断剑怪物-行为说明.html)，查看本项目怪物的一轮流程、选招、11种行动与攻击后走位。全部资源在文件内，不需要联网。

## 使用整理器

在本目录运行 `node preview.cjs`，打开 `http://127.0.0.1:4173/`；也可直接打开 `dist/index.html`。导入 `data/断剑敌人-可读标准版.json` 查看已接入UE的实际结构。导入前先导出个人编辑记录。

整理器的编辑数据保存在浏览器本地存储，不会自动写回仓库，也不会修改UE资产。真实档案不支持通用示例Tick推演，应在UE内验证。

验证工具基础功能：`node verify.cjs`。
